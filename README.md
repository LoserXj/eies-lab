# EIES-Lab website

EIES-Lab (Laboratory for Embodied Intelligence in Energy Systems), The Hong Kong Polytechnic University.

Bilingual (EN `/`, ZH `/zh/`) lab site built on [HugoBlox academic-cv](https://github.com/HugoBlox/hugo-theme-academic-cv) (MIT). Upstream README: `README.hugoblox.md`.

## Run locally

Requires Hugo 0.162 extended, Go, Node 22 and pnpm 10.

    pnpm install
    hugo server            # http://localhost:1313
    pnpm build             # production build into public/ (scenes + Hugo + search index)

## Homepage 3D scene

The homepage hero (`block: hero-scene`) plays a live 3D scene from `scenes/` (three.js, own Vite package in the pnpm workspace) in an iframe, over a poster image. Code and data are deployed on the same server: site at `/`, scene at `/scenes/`, data at `/scene-data/<place>/` (not in git, ~1.6 GB).

    pnpm install
    pnpm scenes:dev        # http://localhost:5180/ (serves ../data as /scene-data/)
    hugo server            # hero loads the scene from :5180 in development

Structure, parameters, deployment and how to add a research theme: `scenes/README.md`.

## Add a member (no page file needed)

1. `data/authors/<slug>.yaml` — English profile; copy an existing member such as `tan-hongjun.yaml`. Set the role, interests and ordering weight.
2. `data/zh/authors/<slug>.yaml` — Chinese overrides only.
3. Avatar: `assets/media/authors/<slug>.jpg` (square).

The Team directory has two sections: Faculty contains `zhiling-guo`; every other author appears in Members, ordered by `weight`. This display grouping does not overwrite author roles or `user_groups`. Portraits are shared with member profiles and oriented before circular cropping. The 11 portraits imported from https://www.chokurei.net/team are recorded in `docs/design/team-portrait-sources.json`; unmatched members keep their initials. The source page labels Zhang Yong'an with an image filename containing “Zhang Rongan”; the visible member caption was used for the match.

Team contact icons use the author's `links` (icon, URL and optional label), shared with the personal profile. Members without configured links show non-clickable Email and Google Scholar placeholders until addresses are added.

The personal page `/team/<slug>/` is generated by `content/team/_content.gotmpl`; papers listing `<slug>` or its equivalent author name in `authors:` appear there automatically.
Set `website` in the author YAML to show the Personal Website button after the biography. Replace the example URL with the member's real website. `education` appears in its own final section. The member publications page shows selected papers first, followed by the complete bibliography.
Research shows up to four featured papers (or the latest four if none are featured). All Publications shows the complete list. Paper details link to their immediate previous and next papers in date order.
Paper links from a profile carry `?from=profile`, so the detail's back button returns to that profile, including after moving between papers. Entries from the publications list or a direct detail URL return to the publications list.
Personal paper details follow the source paper's draft, publication and expiry dates. Chinese details are generated only when `index.zh.md` exists, matching Hugo's translation availability. Local attachment and body links resolve against the source paper bundle; resource links retain their `contexts: [list]` / `[page]` visibility settings.
The extra `demo-paper-3` through `demo-paper-8` bundles are member-only previews: `member_preview: zhiling-guo` selects their owner, while `build: {list: never, render: never}` keeps their source pages out of global publication lists. Their detail views are generated under that member's URL.

## Add a paper / news

- Paper: `content/publications/<name>/index.md` (+ `index.zh.md`). `featured: true` shows it on the homepage.
- News: `content/news/<name>/index.md` (+ `index.zh.md`).

## Look and feel

**Design rules for all contributors: [`DESIGN.md`](DESIGN.md)** (monochrome system; reference material in `docs/design/uber-reference/`).

- Monochrome system (black / white / greys, pill buttons, 12px cards, Inter) in the `HOMEPAGE — monochrome system` block of `assets/css/custom.css`; inner pages still use the earlier site-wide rules above it.
- Homepage blocks: `hero-scene` (3D scene hero), `loop-diagram` (animated closed loop, content in `data/loop.yaml`). Footer: `layouts/_partials/site_footer.html` + `data/site_footer.yaml`.
- Logo: `assets/media/logo.png` (navbar, footer) and `assets/media/icon.png` (favicon) are the PolyU emblem. `static/media/eies-framework.jpg` is the source framework figure the loop diagram is based on.
