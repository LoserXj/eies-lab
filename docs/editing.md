# 在网页上编辑论文、报告、项目、新闻和团队信息

网站用 [Pages CMS](https://pagescms.org) 编辑。每次保存都会提交到 GitHub 仓库 `Chokurei/eies-lab-site` 的 `main` 分支，然后网站自动重新生成，一两分钟后上线。编辑表单由仓库根目录的 `.pages.yml` 定义。

## 一次性设置（管理员）

1. 用仓库所有者的 GitHub 账号登录 <https://app.pagescms.org>，按提示把 Pages CMS 的 GitHub App 安装到 `Chokurei/eies-lab-site`。
2. 在 Pages CMS 的项目设置里邀请成员：有 GitHub 账号的可以加为仓库协作者，没有的可以用邮箱邀请。
3. 仓库 Settings → Pages → Source 选 **GitHub Actions**。
4. 把 `config/_default/hugo.yaml` 里的 `baseURL` 改成正式网址。

## 日常编辑

- 打开 <https://app.pagescms.org>，选择本仓库。左侧栏目：
  - **Team / 团队**：每位成员一条，个人资料、学术报告、项目与成果都在里面编辑
  - **Publications / 论文**
  - **News / 新闻**
- **中英文在同一张表里：** 每个需要翻译的项都是两栏，英文在上、中文紧挨在下面（如“Title / 英文标题”和“中文标题”）。日期、作者、链接、图片这些两种语言共用，只填一次。详见下文“中英文”。
- **网页上的编辑按钮：** 在网站任意页面的地址后加 `?edit=1`，这个浏览器以后就会在右下角显示“编辑此页”。点击后直接打开当前论文、报告、项目或成员的表单。地址后加 `?edit=0` 可以关闭按钮。访客看不到这个按钮。

### 新增论文

- **作者：** “Lab authors”只能选课题组成员，按作者顺序选。
- **其他字段：** DOI 填在 Identifiers 里，PDF、代码等链接加在 Links 里。
- **中英文：** 一句话简介中英文都必填；摘要、标签、图注、作者备注都在英文栏下面填中文。论文题目一般保留英文，中文标题可以不填。

### 新增成员

- **Slug：** 用小写的“姓-名”，例如 `chen-xiaoming`。创建后不要再改，论文是靠它关联到成员的。
- **照片：** 上传正方形照片即可。
- **中英文：** 中文姓名填在“中文姓名”；职位中英文都必填；简介、研究兴趣、教育背景、奖项、技能都是英文一栏、中文一栏。分组只选一次，中文页自动显示中文名称。

### 个人页的各个板块

个人页依次是：简介与数字栏、研究兴趣与教育背景、代表论文（最多 5 篇）、学术报告、项目与成果、技能与爱好、荣誉奖项。还没填的板块会显示“待补充”。数字栏里的“加入课题组”年份取自 Joined the lab 字段。

- **代表论文：** 来自论文栏目，作者里选了这位成员就会出现；勾选 Featured 的排在前面。
- **学术报告、项目与成果：** 就在自己那条资料的最下面编辑，见下文。
- **其他板块：** 在“Team / 团队”里编辑对应字段，包括 Education、Awards、Skills。
- **完整示例：** 参考董克川（`dong-kechuan`）的资料和他名下的报告、项目。

### 学术报告、项目与成果

报告和项目都在个人资料里编辑：打开“Team / 团队”里自己的那条，拉到最下面，有 **Talks / 学术报告** 和 **Projects / 项目与成果** 两个列表。每加一条，网站就会生成一个独立页面（网址 `/talks/<网址名>/`、`/projects/<网址名>/`），并显示在你的个人页上。页面样式固定，只需要填内容。

**新增一场报告：**
1. 在 Talks / 学术报告 下点 **Add an item**。
2. **必填（中英文）：** 标题、一句话简介；再填 Start（开始时间）。
3. **选填：**
   - **Web address / 网址名：** 留空会用“年份-英文标题”。发布后不要再改，否则旧链接会失效。
   - **其他课题组报告人：** 和别人一起报告时选上，这场报告也会出现在他们的个人页上。只需一个人添加，别人不要重复加。
   - **报告信息：** 结束时间、会议名称、活动网址、形式、地点、摘要（中英文各一栏）。
   - **Links：** 加演示文稿、视频、PDF、海报、活动页面。选了 slides，页面上会出现“点击上方演示文稿按钮查看报告内容”的提示。
   - **Figure：** 放报告第一页的截图，配上中英文图注。
   - **Cover image：** 有现场照片时用，会替代自动生成的封面。
4. **保存：** 一两分钟后，报告出现在个人页和 `/talks/` 列表里。尚未举行的报告也会显示。

**新增一个项目：** 在 Projects / 项目与成果 下点 **Add an item**，中英文标题和一句话简介必填（一句话简介是卡片文字，也是页面第一段）。建议再填类型（模型、数据集、代码等）、16:9 封面和链接。正文中英文各一栏，已经预填了四个二级标题，用不到的删掉；每个二级标题都会出现在页面右侧的“本页目录”里。

### 图片和文件

- **封面和配图：** 在图片字段里直接上传，会存到 `assets/media/members/`，网站会自动压缩。16:9 横图效果最好，宽度 1600 像素左右即可。
- **演示文稿、PDF 等文件：** 在 Pages CMS 的 **Media → Talk and project files** 里上传，然后把 `/uploads/works/文件名` 填进 Links 的 URL。也可以直接填外部链接，比如 Google Drive 或 SlideShare。
- **正文里的图片：** 在正文编辑器里插入，也存到 `static/uploads/works/`。

### 新闻

在“News / 新闻”点 **Add an entry**，标题和一句话简介中英文都必填，再填日期和中英文正文。网址为 `/news/<文件夹名>/`。

### 中英文

网站每个页面都有中英文两个版本，后台的每张表都同时管理两种语言：

- **两栏对照：** 每个需要翻译的项都是英文一栏、中文一栏，上下挨着。例如“Role / 职位（英文）”下面就是“职位（中文）”，教育背景的每一条里也是“学位（英文）”“学位（中文）”成对出现。
- **必填项：** 标题和一句话简介（报告、项目、新闻）、一句话简介（论文）、职位（成员）中英文都必须填，否则不能保存。
- **选填项留空就用英文：** 其他中文栏没填时，中文页显示英文内容，页面不会缺东西。
- **共用的只填一次：** 日期、作者、DOI、链接地址、图片、照片、教育起止时间等两种语言共用。
- **文件里怎么存：** 中文栏在文件里是同名加 `_zh` 的字段（`title_zh`、`bio_zh`、`degree_zh` ……），成员的中文姓名是 `name.alternate`。网站生成时，`scripts/build-zh.mjs` 用它们生成中文页面；生成的 `index.zh.md` 和 `data/zh/authors/` 不放进仓库，不要手改。
- **本地预览：** 运行 `pnpm dev`，会先生成中文页再启动网站；改了中文内容后重新运行 `node scripts/build-zh.mjs`。
- **首页、研究、实验室空间、联系方式：** 这几个页面仍然是 `_index.md`（英文）和 `_index.zh.md`（中文）两个文件，由维护网站的人修改。

### 谁可以编辑

- **权限：** Pages CMS 按仓库授权，被邀请的人能编辑所有栏目。请大家只改自己的资料、报告和项目。
- **查看改动：** 每次保存都是一次 GitHub 提交，提交者是保存的人。在仓库的提交记录里能看到谁改了什么，需要时可以撤回。
- **新成员：** 管理员先在“Team / 团队”里建好资料，再到 Pages CMS 的项目设置里邀请此人。之后此人登录就能自己添加报告和项目。

### 页面样式（给维护网站的人）

| 内容 | 页面模板 | 新建模板 |
|---|---|---|
| 报告、项目页面和中文页的生成 | `scripts/build-zh.mjs` | — |
| 报告和项目详情页 | `layouts/works/single.html` + `layouts/_partials/member/work-article.html` | 个人资料里的 talks / projects 列表 |
| 报告和项目列表页 | `layouts/works/list.html` | — |
| 个人页里的报告、项目板块 | `layouts/_partials/hbx/blocks/member-works/block.html` | — |

## 注意

- 保存时如果提示有冲突，说明别人刚改过同一条，刷新后再改。
- 大量导入论文时，仍然可以用 BibTeX：更新仓库根目录的 `publications.bib`，自动化流程会生成论文页面。
